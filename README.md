# UsefulNews

Читает RSS, выбрасывает шум, пересказывает оставшееся по-русски и шлёт в Telegram
по одной новости за раз.

Сделано из раздражения: открываешь ленту за информацией, а выходишь с испорченным
настроением. Здесь нет ленты. Есть источники, которые выбрал ты, и сводка, у которой
есть конец.

## Что он делает

1. Читает ленты из OPML-файла (экспорт из любой RSS-читалки подойдёт).
2. Прогоняет новое через модель: оценка 0–10 по тому, насколько это реальное
   достижение, а не колонка, дайджест или реклама. Всё ниже порога выбрасывается.
3. Для прошедших отбор идёт по ссылке и вытаскивает **текст самой статьи** —
   не тизер из ленты, иначе пересказывать нечего.
4. Пересказывает по-русски: заголовок и абзац с конкретикой — что сделали, как
   работает, какие числа.
5. Шлёт в Telegram. Одна новость — одно сообщение.

Каждая третья новость берётся из «позитивных» лент, чтобы не получался сплошной
техрадар.

## Чего он не делает

- Не шлёт дайджесты и подборки ссылок — они режутся на отборе.
- Не шлёт колонки вида «нам срочно нужно» и «что если бы» — это не новости.
- Не пересказывает тизеры: если по ссылке меньше 500 символов текста, запись
  выбрасывается.
- Не хранит ничего, кроме списка уже отправленного.

## Установка

```bash
git clone <repo>
cd UsefulNews

python3 -m venv .venv
.venv/bin/pip install feedparser requests trafilatura
```

Создай `.env` рядом со скриптом:

```bash
export TELEGRAM_TOKEN=...      # от @BotFather
export TELEGRAM_CHAT=...       # свой id, или -100... для канала
export MODEL_API_KEY=...       # OpenRouter или Anthropic
```

В `newsbot.py` впиши имя модели в `MODEL`. Провайдер переключается одной строкой
(`PROVIDER = "openrouter"` или `"anthropic"`).

Положи рядом свой OPML и проверь руками:

```bash
. .env && .venv/bin/python newsbot.py
```

Должно прийти одно сообщение.

## Запуск по расписанию

```
0 9-23 * * * cd ~/UsefulNews && . .env && .venv/bin/python newsbot.py >> newsbot.log 2>&1
```

В репе лежит и workflow для GitHub Actions, если не хочешь держать машину включённой.
Состояние тогда коммитится обратно в репу, так что `newsbot_state.json` из
`.gitignore` надо убрать.

## Настройки

Всё наверху файла:

| что | зачем |
|---|---|
| `MIN_SCORE` | порог отбора. Выше — меньше новостей, но чище |
| `MIN_ARTICLE_CHARS` | короче этого считается тизером и выбрасывается |
| `POSITIVE_EVERY` | каждая N-я новость из позитивных лент |
| `POSITIVE_FEEDS` | какие ленты считать позитивными (по названию из OPML) |
| `REFRESH_HOURS` | как часто заново обходить ленты |

Главное же живёт не в настройках, а в двух промптах — `RANK_PROMPT` решает, что
вообще достойно отправки, `SUMMARY_PROMPT` задаёт тон пересказа. Правь их, а не числа.

## Что стоит знать

**Не все сайты отдают текст.** Phys.org отвечает 403, Ars Technica — 405. Лечения
нет, просто не держи их в OPML: без текста статьи пересказывать нечего.

**Модель должна держать формат.** Бесплатные часто не держат: вываливают
рассуждения, обрывают ответ на середине, возвращают пустоту. Если в Telegram лезет
мусор или ничего не приходит — скорее всего дело в модели, а не в коде. Лимиты
токенов здесь подняты с запасом именно поэтому.

**Кириллица дорогая.** Один русский символ — два-три токена. Если пересказ
обрывается на полуслове, поднимай `max_tokens` в `summarize`.
